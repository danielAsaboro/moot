# ADR D18: Manual QA sign-off before every release

- Status: accepted
- Date: 2024-11-01
- Owner: Sofia Rossi (Frontend lead)
- Systems: web-app

## Context

- There is no end-to-end test coverage of the web app.

## Decision

A person walks the release checklist in staging before each production release.

## Consequences

Teams follow this until it is explicitly revisited. Exceptions need the owner's approval.
