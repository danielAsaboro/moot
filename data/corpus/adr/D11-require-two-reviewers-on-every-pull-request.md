# ADR D11: Require two reviewers on every pull request

- Status: accepted
- Date: 2024-10-01
- Owner: Tomi Adeyemi (CTO)
- Systems: infra

## Context

- CI runs no automated test suite.

## Decision

Every PR needs two approvals before merge.

## Consequences

Teams follow this until it is explicitly revisited. Exceptions need the owner's approval.
