# ADR D20: Pin the mobile app to React Native 0.72

- Status: accepted
- Date: 2025-09-01
- Owner: Sofia Rossi (Frontend lead)
- Systems: mobile-app

## Context

- The payments SDK does not support the React Native New Architecture.

## Decision

The mobile app stays on React Native 0.72 and the old architecture.

## Consequences

Teams follow this until it is explicitly revisited. Exceptions need the owner's approval.
